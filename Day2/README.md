# Tip Calculator

**Description:**  
A simple Python program to calculate the tip and split a bill among multiple people. This project helps practice working with **different data types** and arithmetic operations in Python.

**Key Concepts Learned:**  
- Using `float` and `int` data types  
- Basic arithmetic operations (`+`, `*`, `/`)  
- Collecting user input with `input()`  
- Formatting numbers to 2 decimal places  
- Step-by-step calculation vs. inline calculation  
- Optional: using `"{:.2f}".format()` or f-strings for clean output
