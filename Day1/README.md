# Band Name Generator

**Description:**  
A simple Python program to practice **string concatenation**. The program asks the user for the city they grew up in and their pet’s name, then combines them to generate a creative band name.

**Key Concepts Learned:**  
- String concatenation using `+` operator  
- Using `input()` to collect user data  
- Basic output formatting with `print()`  
- Optional: using f-strings for cleaner concatenation
