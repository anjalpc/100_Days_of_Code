# Rock Paper Scissors Game

**Description:**  
A simple Python game that lets the user play **Rock, Paper, Scissors** against the computer. This project helps practice **conditional statements, lists, and random number generation**.

**Key Concepts Learned:**  
- Using `if`, `elif`, and `else` to implement game logic  
- Working with Python **lists** to store ASCII art for display  
- Collecting and validating user input with `input()`  
- Generating random numbers with `random.randint()` for computer choices  
- Comparing values to determine outcomes (win, lose, tie)  
- Displaying multi-line strings (ASCII art)
